# 降级策略清单（Fallback Policy）

> 对应学习清单 D2-3。目的：把"出问题怎么办"固化成文档，不再临场反应。
> 原则：**失败要可感知、可恢复、不静默吞掉**——每一步失败都有明确动作与用户可见信息。

---

## 场景 A：LLM API 连续失败（连接 / 限流 / 超时 / 5xx）

**触发条件**：`agent/llm.py` 重试耗尽（默认 3 次、间隔 1s/2s/4s）仍失败；
或抛出的错误不可重试（4xx：鉴权失败、参数错误）。

**动作**：
1. 不再重试（重试已由 llm.py 内部完成，不无限重试）
2. 异常向上抛到 CLI 层

**用户可见信息**：
```
错误: <异常信息>
```
REPL 模式打印红色错误后**继续等待下一条输入**（会话不崩）；
单次提问模式打印错误后退出（退出码非 0）。

**实现位置**：`agent_cli.py` main() 的 try/except；`agent/llm.py` chat()。

---

## 场景 B：工具连续返回错误

**触发条件**：工具 handler 抛异常 / 参数解析失败 / 未知工具。

**动作**：错误**不向上抛**，转成字符串作为 tool 消息回喂模型
（`[工具执行出错] TypeError: ...`），让模型自己决定下一步：
重试、换参数、换工具、或如实告知用户失败。

**用户可见信息**：模型最终给出的答复（含失败说明）。

**实现位置**：`agent/tools/registry.py` execute()。
若模型在 max_steps 内反复失败（如"读同一文件失败 N 次"），
由 max_steps 保险丝（场景 C）兜底终止。

---

## 场景 C：max_steps 耗尽（任务未完成）

**触发条件**：ReAct 循环达到上限（默认 15 步）仍未给出最终答案。

**动作**：停止循环，返回提示文本，不再调 LLM。

**用户可见信息**：
```
达到最大步数，任务未完成。
```
（升级方案：改为输出已完成的中间结论 + 未完成原因，见备注）

**实现位置**：`agent/core.py` run() 的 for 循环出口。

---

## 场景 D：用户拒绝工具审批

**触发条件**：confirm 级工具（write_file / run_shell）执行前，
approver 返回 False 或审批回调自身抛异常。

**动作**：不执行工具，返回 `[用户拒绝]` 作为 tool 消息回喂模型
——模型会感知"用户不想做这个操作"，应换方案或询问用户。

**用户可见信息**：模型换方案后的答复；verbose 模式可见 `[用户拒绝]` 结果。

**实现位置**：`agent/tools/registry.py` execute() 的审批分支；
approver 由 `agent_cli.py` `_make_approver()` 注入（--yes 跳过审批）。

---

## 场景 E：上下文超窗（记忆兜底）

**触发条件**：消息总量超过 compress_threshold，或窗口轮数超过 window_rounds。

**动作**：
1. 窗口滑动（按轮）：超 window_rounds 轮时，滑出最旧轮次——先
   `extract_summary` 增量摘要 + `archive` 原文落盘，再丢弃
2. 总量兜底（按预算）：总量超 compress_threshold 时，从**最老轮**开始滑出，
   直到达标或只剩最近一轮——**保留最近轮次的完整原文**，
   当前任务刚读入的内容不会被无差别清空（跨轮失忆 bug 修复点）
3. 单轮本身超预算（一次读了超大文件）：保留原文供当前任务引用，
   由模型窗口容纳；API 拒收的极端情况由用户调低阈值/减小读取兜底
4. 原文始终在磁盘（memory_store.jsonl），摘要只是索引

**用户可见信息**：verbose 模式打印
`memory 窗口超限，滑出 N 条旧消息` / `memory 总量超预算，滑出 N 条最旧消息` /
`memory 最近轮次已超预算，保留原文供当前任务引用`。

**实现位置**：`agent/core.py` `_trim_window()` / `_emergency_compress()`；
`agent/memory.py` extract_summary / archive。

---

## 场景 F：知识索引损坏

**触发条件**：knowledge_index.json 无法解析（JSON 损坏）。

**动作**：降级为空索引，不阻塞启动；下次 add() 时重建文件（自愈）。

**用户可见信息**：无（静默降级，不影响主流程）。

**实现位置**：`agent/knowledge.py` `_load()`。

---

## 决策速查

| 场景 | 能否恢复 | 策略 | 用户可见 |
|---|---|---|---|
| A API 失败 | 重试 3 次 | 重试耗尽后抛错 | 红色错误提示 |
| B 工具错误 | 模型自愈 | 错误回喂，模型决定 | 模型答复 |
| C 步数耗尽 | 否 | 保险丝终止 | "达到最大步数" |
| D 用户拒绝 | 是 | 拒绝回喂，换方案 | 模型换方案 |
| E 上下文超窗 | 是 | 摘要 + 外置 | verbose 日志 |
| F 索引损坏 | 是 | 空索引自愈 | 无 |
